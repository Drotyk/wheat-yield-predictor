# Wheat Yield Predictor (Прогнозатор урожайності пшениці)

[![CI](https://github.com/Drotyk/wheat-yield-predictor/actions/workflows/ci.yml/badge.svg)](https://github.com/Drotyk/wheat-yield-predictor/actions/workflows/ci.yml)

Цей проєкт являє собою консольну програму на C++ (стандарт C++17) для прогнозування врожайності пшениці на основі різних агрономічних, ґрунтово-кліматичних та погодних факторів.

---

## Основні можливості

Програма дозволяє користувачу покроково обрати ключові параметри, які впливають на ріст та розвиток пшениці, і на основі математичної моделі розраховує орієнтовну врожайність (у тоннах на гектар, т/га).

Враховуються такі чинники:
- **Сорт пшениці:** (наприклад, Подолянка, Краєвид, Скаген) — базові показники врожайності, стійкість до гербіцидів, посухостійкість, зимостійкість, вміст білка/клейковини та коефіцієнти чутливості сорту.
- **Тип ґрунту:** Чорнозем, Суглинок, Піщаний, Лучний (з відповідними коефіцієнтами родючості).
- **Добрива:** Вплив різних типів добрив (NPK 16-16-16, Амофос, Карбамід або без добрив).
- **Агрокліматичний регіон:** Полісся, Лісостеп, Степ, Південний степ, Карпати.
- **Погодні умови по сезонах:** Можливість задати погоду для весни, літа, осені та зими (дощова, спекотна, помірна, суха, м'яка, вітряна).

### Особливості реалізації
1. **Зовнішня конфігурація (JSON):** Усі переліки сортів, ґрунтів, добрив, регіонів та погодних умов винесені у зовнішній файл `data/config.json`. Ви можете змінювати або додавати нові дані без перекомпіляції проєкту.
2. **Валідація даних:** При завантаженні конфігурації перевіряється відсутність порожніх списків та коректність меж врожайності (`minYield <= avgYield <= maxYield`).
3. **Захист від некоректного введення:** Інтерактивне консольне меню обробляє нечислові значення (наприклад, літери або випадкові символи) без збоїв потоку `cin`.
4. **Розширена модель прогнозування:** Враховуються бонуси чутливості сорту (`soilBonus`, `weatherBonus`, `fertilizerBonus`, `regionBonus`, `yieldPotential`) для підсилення або послаблення відповідних чинників.
5. **Покриття юніт-тестами:** Впроваджено 15 юніт-тестів на фреймворку **Catch2 v3**, які перевіряють математичні розрахунки, обрізання результатів (clamping), погодні ефекти та валідацію конфігурації.

## Вимоги до системи

- Компілятор C++ з підтримкою стандарту **C++17** (`g++` або `clang++`).
- Утиліта `make`.
- Бібліотека **nlohmann-json3-dev** (для парсингу JSON).
- Фреймворк **Catch2** v3 (для запуску юніт-тестів).

На дистрибутивах Ubuntu / Debian необхідні бібліотеки можна встановити командою:
```bash
sudo apt-get install -y nlohmann-json3-dev catch2
```

---

## Збирання та запуск

1. Відкрийте термінал у кореневій папці проєкту.
2. Виконайте команду для компіляції:
   ```bash
   make
   ```
3. Запустіть скомпільовану програму:
   ```bash
   ./wheat_predictor
   ```

Якщо ви бажаєте підключити інший файл `main.cpp` з власною логікою, зберіть проєкт так:
```bash
make MAIN=/шлях/до/вашого/main.cpp
```

---

## Тестування

Для збирання та запуску юніт-тестів виконайте:
```bash
make test
```

Усі 15 тест-кейсів перевіряють:
- Коректність базового розрахунку врожайності.
- Обмеження за мінімальною та максимальною врожайністю (clamping).
- Вплив добрив, родючості ґрунту, погодних умов та стійкості до гербіцидів.
- Завантаження та валідацію файлу `data/config.json`.

## Неперервна інтеграція (CI)

У проєкті налаштовано автоматичний процес **CI (Continuous Integration)** на базі GitHub Actions ([.github/workflows/ci.yml](file://.github/workflows/ci.yml)).

При кожному push або pull request у гілки `master` або `main` workflow автоматично виконує такі кроки:
1. **Встановлення залежностей:** підготовка середовища `g++`, `make`, `nlohmann-json3-dev`, `catch2`, `cppcheck`.
2. **Статичний аналіз коду (Linting):** перевірка якості та потенційних помилок за допомогою `cppcheck`.
3. **Збирання проєкту:** компіляція бінарного файлу через `make`.
4. **Автоматичне тестування:** запуск повного набору юніт-тестів через `make test`.

> [!NOTE]
> Процес класифікується саме як **CI** (без CD), оскільки автоматичне розгортання (deployment) у даній консольній утиліті відсутнє. Значок у заголовку README є динамічним та показує актуальний стан останнього запускa workflow.

## Використання

Після запуску програми використовуйте інтерактивне меню в консолі. Вам буде запропоновано покроково обрати:
1. Сорт пшениці.
2. Тип ґрунту.
3. Тип добрива.
4. Агрокліматичний регіон України.
5. Погодні умови для кожного з чотирьох сезонів (можна обрати кілька умов для одного сезону, вводячи їх номери через пробіл, а потім `0` для переходу далі).

Після введення всіх даних програма проаналізує їх та виведе детальний підсумковий розрахунок прогнозованої врожайності.
